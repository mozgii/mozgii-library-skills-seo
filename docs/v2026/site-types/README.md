# SEO by site type

SEO for a kind of site rather than a kind of engine. Four skills: `international-seo` for several countries or languages, `local-seo` for physical locations, `ecommerce-seo` for stores, and `programmatic-seo` for pages generated from data. Use one when the site's type changes the plan.
