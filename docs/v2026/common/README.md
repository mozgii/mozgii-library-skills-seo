# Common SEO skills

SEO work that stays the same whichever engine you target. Sixteen skills: `seo-audit`, `crawling-and-indexing`, `javascript-seo`, `xml-sitemaps`, `canonical-urls`, `site-migrations`, `internal-linking`, `core-web-vitals`, `structured-data`, `image-and-video-seo`, `keyword-research`, `on-page-seo`, `content-briefs`, `link-building`, `ai-search-visibility` and `seo-measurement`. Start here for any site, and add an engine's group when a console, a crawler or a policy of that engine is involved.
