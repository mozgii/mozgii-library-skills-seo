# Content brief template with an example

The content brief template fits on one page. Fill every field; a field left empty is a question for the owner, not
for the writer to guess.

## Content brief template

The content brief template below is copied into the task or document for each new page.

```text
Page:              <working title>               URL: /<path>/            Type: <article | service | category | comparison>
Main phrase:       <phrase>  (<volume>/month, <source>, <month>)        Intent: <class>
Secondary phrases: <3–6 phrases with volumes>
Reader:            <who, what they know, what they must decide or do>
Answer (lead):     <the answer in two sentences>
SERP notes:        <page types in the top 10; features; what all cover; what none has>
Outline:
  H2 <sub-question 1>   point: <what it says>   proof: <data, example, source>
  H2 <sub-question 2>   ...
Proof to supply:   <numbers, cases, quotes, tests; who provides each>
Entities/terms:    <names, standards, products the page must explain>
Links:             up: <hub>   out: <pages>   in: <pages that will link here, with anchor>
Title draft:       <≤ 60 characters>
Description draft: <120–160 characters>
Author / reviewer: <name, credentials> / <name for YMYL topics>
Done when:         <questions the reader can answer after reading>
```

## Example brief for an informational article

The example below is a filled brief for an article on a running shop's site.

```text
Page:              How long do trail running shoes last?     URL: /guides/trail-shoe-lifespan/   Type: article
Main phrase:       how long do trail running shoes last  (1,300/month, Keyword Planner range midpoint, 2026-09)
Intent:            informational, with a buying follow-up
Secondary phrases: when to replace trail running shoes (480); trail shoes mileage (210); signs of worn out running shoes (390)
Reader:            runs trails 2–4 times a week; owns one pair; wants to know if it is time to buy
Answer (lead):     Most trail running shoes last 500–800 km. Replace them earlier when the lugs are worn flat,
                   the midsole creases deeply, or new aches appear after runs.
SERP notes:        top 10: 7 guides, 2 brand pages, 1 forum thread; PAA present; none show measured lug wear
Outline:
  H2 How many kilometres trail shoes last     point: 500–800 km, by terrain and weight   proof: our 40-pair wear test
  H2 Five signs your trail shoes are worn out  point: lugs, midsole, upper, outsole, pain proof: photos from the test
  H2 Why trail shoes wear faster than road shoes point: rock, mud, softer rubber          proof: rubber hardness specs
  H2 How to make trail shoes last longer       point: rotation, drying, cleaning          proof: coach quote
  H2 Which trail shoes last longest            point: outsole compounds compared          proof: test table, link to category
Proof to supply:   wear test data (store team); 6 photos; quote from a running coach
Entities/terms:    lugs, midsole foam (EVA, PEBA), rock plate, outsole compound, drop
Links:             up: /guides/   out: /running-shoes/trail/, /guides/choosing-trail-shoes/
                   in: /running-shoes/trail/ ("how long trail shoes last"), /guides/choosing-trail-shoes/
Title draft:       How long do trail running shoes last? (Tested)
Description draft: Most trail shoes last 500–800 km. See our 40-pair wear test, the five signs a pair is worn out,
                   and how to make yours last longer.
Author / reviewer: store running coach (12 years coaching trail runners) / not YMYL
Done when:         reader knows their pair's likely lifespan, can check the five signs, and knows what to buy next
```
