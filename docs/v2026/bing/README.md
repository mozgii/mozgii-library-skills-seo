# Bing SEO skills

Microsoft's search engine and Copilot. Three skills: `bing-seo` for the guidelines and what differs from Google, `bing-webmaster-tools` for the console and its API, and `bing-ai-and-copilot` for AI Performance and the AI preferences. Use them for traffic from the US, Japan or DuckDuckGo.
