# Yandex SEO skills

Search in Russian-speaking markets. Three skills: `yandex-seo` for Webmaster, regions and filters, `yandex-wordstat` for demand, and `russian-language-seo` for the text. `russian-language-seo` also serves Russian text for Google, so use it for any Russian page, whichever engine it targets.
