# Natural Russian editing passes

Редактура в три прохода убирает канцелярит и приметы машинного текста: сначала орфография, потом словарь, потом
структура предложений. Главный вопрос после правки: прочитав текст, решит ли носитель языка, что его написал человек?
Быстрее всего выдают текст слова «данный» и «является»; их правят первыми.

## Проход 1: орфография, е и ё

Буква ё в обычных словах по умолчанию заменяется на е: в нейтральном веб-тексте ё почти не пишут, а Яндекс не
различает е и ё, поэтому на ранжирование замена не влияет. Если сайт последовательно пишет ё, следуйте сайту.

| С ё | Без ё |
|---|---|
| всё, ещё, её, неё | все, еще, ее, нее |
| чёрный, жёлтый, зелёный, тёмный | черный, желтый, зеленый, темный |
| лёгкий, тяжёлый, твёрдый, дешёвый | легкий, тяжелый, твердый, дешевый |
| шёл, пришёл, нашёл, прошёл | шел, пришел, нашел, прошел |
| приём, объём, подъём, съёмка | прием, объем, подъем, съемка |
| отчёт, расчёт, учёт, счёт, зачёт | отчет, расчет, учет, счет, зачет |
| самолёт, полёт, учёный | самолет, полет, ученый |
| включённый, сохранённый, разделённый | включенный, сохраненный, разделенный |

В именах ё сохраняется: Фёдор, Артём, Алёна, Семён, Пётр. Оставляйте ё и там, где без нее смысл станет двусмысленным
(«всё» и «все», «узнаёт» и «узнает»), если контекст не снимает двусмысленность.

## Проход 2: словарь

Слова с самым сильным канцелярским и машинным оттенком заменяются всегда.

**данный, данная, данное** заменяются на этот, эта, это во всех случаях, кроме «данные» в значении информации.

| Было | Стало |
|---|---|
| данный подход | этот подход |
| в данном случае | в этом случае, здесь |
| на данный момент | сейчас |
| данные результаты | эти результаты |
| данные (информация) | оставить |

**являться** убирается перестройкой фразы.

| Было | Стало |
|---|---|
| Это является проблемой | Это проблема |
| Метод является эффективным | Метод работает |
| Компания является лидером | Компания — лидер |
| Целью является достижение | Цель — достичь |
| Ключевым фактором является | Главное здесь — |

**осуществлять** заменяется прямым глаголом.

| Было | Стало |
|---|---|
| осуществлять контроль | контролировать |
| осуществлять поддержку | поддерживать |
| осуществлять доставку | доставлять |
| осуществить переход | перейти |
| осуществляется процесс | идет процесс |

## Канцелярские обороты и безличные конструкции

Канцелярские связки и безличные обороты заменяются простыми словами.

| Было | Стало |
|---|---|
| в рамках | в, по, за, в пределах |
| ввиду того, что | потому что, так как |
| вместе с тем | но, при этом, однако |
| что касается | насчет, о, по |
| следует отметить, что | стоит сказать; или просто факт |
| необходимо подчеркнуть | важно: |
| таким образом (в начале абзаца) | итак, значит, в итоге |
| в заключение | в итоге, наконец |
| наряду с | вместе с, помимо |
| порядка (числа) | около, примерно |
| исходя из | из, судя по, на основе |
| на основании вышеизложенного | поэтому |
| следует | нужно, надо, стоит |
| необходимо | нужно, надо |
| рекомендуется | лучше, стоит, советуем |
| представляется возможным | можно |
| не представляется возможным | нельзя, не получится |
| имеется возможность | можно |

В официальных документах, инструкциях и договорах «следует», «необходимо», «рекомендуется» уместны; заменяйте их в
нейтральном и разговорном тексте.

## Глаголы, существительные и прилагательные

Книжные глаголы и пустые прилагательные заменяются, когда позволяет контекст.

| Было | Стало | Примечание |
|---|---|---|
| функционировать | работать | почти всегда |
| производить (абстрактно) | делать, выполнять | «производить впечатление» оставить |
| имплементировать | внедрять | |
| верифицировать | проверять | |
| идентифицировать | определять, находить | |
| нивелировать | сглаживать, снижать | |
| минимизировать | снижать, сокращать | в формальном тексте допустимо |
| коммуницировать | общаться, писать | |
| актуальный | важный, текущий | «актуальные данные» значит «текущие данные»: проверьте смысл |
| ключевой аспект | главное, суть | |
| немаловажный | важный | |
| целый ряд | несколько, число | |
| комплексный | полный | «комплексный подход» часто можно убрать |
| колоссальный | огромный | |

## Проход 3: структура

Структурный проход меняет форму предложений, а не слова.

**Тире.** Длинное тире между подлежащим и сказуемым-существительным правильно и остается: «Москва — столица России»,
«Главное правило — не торопиться». Тире почти в каждом предложении и тире-связка вместо запятой, двоеточия или точки
выдают машинный текст: «Это — важно» правится на «Это важно».

**Действительный залог.** Страдательные обороты переводятся в действительные: «Было принято решение» на «Решили»,
«Может быть использовано» на «Можно использовать», «Было разработано» на «Разработали».

**Длина предложений.** Машинный русский текст ровный: почти все предложения по 18–30 слов. Смешивайте короткие
утвердительные предложения с длинными.

**Причастные и деепричастные обороты.** Не больше одного оборота в предложении. «Разработанный командой проект,
реализованный в сжатые сроки, позволил достичь поставленных целей» правится на «Команда разработала проект за месяц.
Цели достигнуты».

## Типовые машинные фразы и их правка

Типовые машинные фразы переписываются целиком.

| Машинная фраза | Правка |
|---|---|
| Данный подход является эффективным решением проблемы. | Этот подход решает проблему. |
| Следует отметить, что данный метод позволяет обеспечить высокое качество. | Этот метод дает высокое качество. |
| В рамках данного проекта осуществляется разработка нового продукта. | В проекте разрабатывают новый продукт. |
| Ввиду того, что данная задача является приоритетной, необходимо сосредоточить усилия. | Задача приоритетная, поэтому нужно сосредоточиться на ней. |
| Таким образом, можно констатировать, что цели достигнуты. | Итак, цели достигнуты. |
| Немаловажным аспектом является то, что… | Важно и то, что… |
| Целый ряд факторов свидетельствует о том, что… | Несколько факторов показывают, что… |

## Подводные камни редактуры

Подводные камни ниже приводят к правкам, которые портят правильный текст.

1. **Замена ё в именах.** Фёдор, Артём, Пётр остаются с ё.
2. **Удаление тире между подлежащим и сказуемым.** «Цель — победить» написано верно.
3. **Слепая замена «актуальный».** «Актуальные данные» означает «текущие», а не «важные».
4. **Правка безличных оборотов в официальном тексте.** В инструкциях и договорах они нормальны.
5. **Удаление всех причастных оборотов.** Сигнал машинного текста в нагромождении, а не в самом обороте.
