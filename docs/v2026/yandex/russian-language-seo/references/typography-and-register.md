## Регистр текста на сайте

Регистр текста на сайте нейтрально-деловой: к читателю обращаются на «вы», глаголы важнее существительных.

- Обращение «вы» со строчной буквы. Прописная «Вы» уместна в личном письме; на сайте она звучит как рассылка.
- Глаголы вместо отглагольных существительных: «запускаем за 30 дней», а не «осуществляем запуск в 30-дневный срок».
- Одна мысль в предложении, одно утверждение в абзаце. Руководители просматривают текст; сплошной текст пропускают.
- Сначала числа: «30 дней», «гарантия 3 года». Число доказывает, прилагательное шумит.
- Без недоказанных превосходных степеней: «лучший», «уникальный», «инновационный», «лидер рынка» требуют
  подтверждения по закону о рекламе (38-ФЗ).
- Кнопки в инфинитиве («Получить смету», «Обсудить проект»); ссылки существительными («Проекты», «Условия»).
- Заголовок блока до восьми слов; если нужен знак препинания внутри, это два заголовка.

## Типографика в коде

Типографика в коде задается символами и сущностями, а числа лучше форматировать через `Intl`.

| Элемент | Писать | Не писать |
|---|---|---|
| Кавычки | «ёлочки», вложенные „лапки“ | "прямые" или “английские” |
| Диапазон чисел | `5–7 дней` (короткое тире без пробелов) | `5-7`, `5 — 7` |
| Число и единица | `30&nbsp;дней`, `1&nbsp;млн&nbsp;₽` | обычный пробел, при котором единица переносится |
| Тысячи | `1 500 000` (неразрывный пробел U+00A0 из `Intl` для ru-RU) | `1,500,000`, `1.500.000` |
| Десятичные | `2,5 млн` | `2.5 млн` |
| Валюта | `₽` после числа через неразрывный пробел, или `руб.` | `RUB`, `р.` |
| Проценты | `40%` без пробела (веб-традиция; ГОСТ допускает пробел, выберите одно) | вперемешку |
| Однобуквенные предлоги | `в&nbsp;срок`, `с&nbsp;гарантией` | предлог в конце строки |
| Даты | `24 сентября 2026`, `24.09.2026` | `09/24/2026`, `2026-09-24` в тексте |
| Многоточие | `…` (один символ) | `...` |
| Сокращения | `и&nbsp;т.&nbsp;д.`, `т.&nbsp;е.` | `итд` |

В JSX `&nbsp;` работает внутри текста; в строковых литералах используйте символ U+00A0. Числа форматирует `Intl`:

```ts
const rub = new Intl.NumberFormat("ru-RU", { style: "currency", currency: "RUB", maximumFractionDigits: 0 });
rub.format(1500000);                           // "1 500 000 ₽"
new Intl.NumberFormat("ru-RU").format(2.5);   // "2,5"
```

## Согласование с числами

Русские числительные требуют трех форм существительного, поэтому жестко прописанное «дней» ломается на 1, 2, 21, 22.

```ts
const rules = new Intl.PluralRules("ru-RU");
const DAYS = { one: "день", few: "дня", many: "дней", other: "дней" } as const;
export const days = (n: number) => `${n} ${DAYS[rules.select(n) as keyof typeof DAYS]}`;
days(1);  // 1 день    days(3); // 3 дня    days(30); // 30 дней    days(21); // 21 день
```

Частые ловушки падежей: «согласно договору» (дательный), «в течение 30 дней» (длительность), «за 30 дней» (срок),
«оплата по факту», «скидка 10% на услугу». Если сомневаетесь, перестройте фразу так, чтобы число стало подлежащим:
«30 дней до запуска».

## Слова по 168-ФЗ

Поправки к закону о государственном языке (168-ФЗ) с 1 марта 2026 года требуют русского языка в информации для
потребителей; иностранные слова остаются, только если в нормативных словарях нет общеупотребительного русского
аналога, а зарегистрированные товарные знаки не меняются. Уточняйте актуальные разъяснения перед запуском.

| Иностранное слово | Для текста интерфейса и сайта | Примечание |
|---|---|---|
| софт | программа, ПО | |
| фикс-прайс | фиксированная цена | |
| дедлайн | срок, срок сдачи | |
| кейс | проект, пример работы, история клиента | адрес `/cases` не считается текстом интерфейса |
| фидбэк | отзыв, обратная связь | |
| митинг | встреча | |
| колл | звонок | |
| саппорт | поддержка | |
| апдейт | обновление | |
| лендинг | страница, сайт | |
| онбординг | запуск, ввод в работу | |
| дашборд | панель, панель показателей | |
| воркфлоу | процесс | |
| таргет | цель | |
| скилы | навыки | |
| аутсорс | внешняя команда, подряд | |
| IT в тексте | ИТ | |
| NDA | соглашение о неразглашении | NDA в скобках при первом упоминании |

## Шаблоны блоков

Шаблоны блоков задают длину и форму типовых элементов страницы.

```text
Надзаголовок : одно-два слова, словарь доверия («Проекты», «Условия», «Гарантии»)
Заголовок    : результат плюс снятый страх, до 8 слов
Лид          : 1–2 предложения, одно число, с точки зрения читателя
Заголовок карточки : 2–5 слов, именная группа
Текст карточки     : до 2 предложений, в конце конкретный результат
Метрика      : число и единица в одной строке, подпись до 6 слов
Кнопка       : глагол в инфинитиве плюс объект («Рассчитать стоимость»)
Поля формы   : существительное («Телефон или почта»), подсказка показывает формат («+7 900 000-00-00»)
Ошибки       : что сделать, а не что сломалось («Укажите телефон или почту»)
```

## Таблица символов и правила

Таблица символов перечисляет знаки русской типографики с их кодами.

| Название | Символ | Unicode | HTML |
|---|---|---|---|
| Открывающая кавычка | « | U+00AB | `&laquo;` |
| Закрывающая кавычка | » | U+00BB | `&raquo;` |
| Вложенная открывающая | „ | U+201E | `&bdquo;` |
| Вложенная закрывающая | “ | U+201C | `&ldquo;` |
| Короткое тире (диапазоны) | – | U+2013 | `&ndash;` |
| Минус | − | U+2212 | `&minus;` |
| Неразрывный пробел | | U+00A0 | `&nbsp;` |
| Узкий неразрывный пробел (тысячи) | | U+202F | `&#8239;` |
| Многоточие | … | U+2026 | `&hellip;` |
| Рубль | ₽ | U+20BD | `&#8381;` |
| Знак умножения | × | U+00D7 | `&times;` |

Правила:

- Неразрывный пробел после одно- и двухбуквенных предлогов и союзов (в, к, с, у, о, и, а, но, на, за, по, до, от,
  из), перед «₽», между числом и единицей, внутри «и т. д.», между инициалами и фамилией.
- Длинное тире как связка между частями предложения убирается на проходе 4; где нужна пауза, ставьте двоеточие или
  делите предложение. Диапазоны пишутся коротким тире без пробелов.
- Числа до десяти в тексте словами («три этапа»), в метриках и списках цифрами.
- Тысячи отделяются узким неразрывным пробелом: в таблицах с четырех знаков, в тексте с пяти (`1500 ₽`, `15 000 ₽`).
- Время `10:00–19:00`, дни недели «пн–пт».
- Телефон `+7 900 000-00-00`.
- Переносы длинных слов на узких экранах: `hyphens: auto` при `lang="ru"` на `<html>`, только для основного текста.
