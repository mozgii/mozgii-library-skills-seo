# Naver SEO skills

Search in South Korea. Two skills: `naver-search-advisor` gets a site registered, collected by Yeti and indexed; `naver-seo` covers titles, C-Rank, Blog and AI Briefing. Start with `naver-search-advisor` when a site is missing from Naver.
