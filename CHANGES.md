# Changes

## 1.3.1 - 2026-11-01

The Yandex Wordstat demand script now sends search phrases over HTTPS and stops if a service tries to redirect it to an unencrypted address, so nobody on the network can read them. Results stay the same.

## 1.3.0 - 2026-11-01

The library is now named `mozgii-library-skills-seo`; the kind comes first. It needs MOZGII 0.1.0 or later. The skills did not change.
